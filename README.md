## 🧪 Research

### AutoPipeline-AD

An automated framework for **multi-objective anomaly detection on IoT and edge devices**.

The idea is simple:

> **Don't just find the most accurate model. Find the model that makes sense for the hardware it's going to run on.**

The pipeline explores:

**Dataset → Configuration → Label-aware routing → Model training → Hyperparameter optimisation → Threshold calibration → Hardware-aware evaluation → Deployment-ready ranking**

Currently working with:

* **Supervised, unsupervised & semi-supervised anomaly detection**
* **Random Forest / Decision Trees**
* **LOF / Isolation Forest**
* **Bayesian hyperparameter optimisation with Optuna**
* **Hardware-aware model evaluation**
* **Memory-efficient deployment considerations**
* **SKAB & CIC-IDS datasets**

Because a model with 99% accuracy isn't particularly impressive if the device can't run it.
